## 🌌 Overview

**ARKEEN SERPENT** is a modern, space-themed arcade game that reimagines the classic Snake gameplay. Built as a high-performance web application and seamlessly integrated as a Telegram Mini App, it offers a visually stunning and highly customizable gaming experience. 

Navigate through infinite cosmic realms, build massive combos, and survive the deadly speeds of the Insane difficulty.

---

## ✨ Key Features

### ⚔️ Dynamic Difficulty System
Choose your challenge and face the cosmos:
- 🌱 **EASY:** Slow & forgiving (180ms)
- ⚔️ **NORMAL:** Balanced challenge (140ms)
- 🔥 **HARD:** Fast & deadly (110ms)
- 💀 **INSANE:** Serpent god mode (85ms)

### 🎨 5 Unique Visual Realms
Immerse yourself in beautifully crafted cosmic environments:
- 🌌 **VOID:** Infinite darkness
- 🌙 **MOON:** Silver starlight
- 🌿 **EMERALD:** Verdant garden
- 🔥 **CRIMSON:** Blood nebula
- 👑 **ROYAL:** Golden empire

### 🎮 Advanced Gameplay Mechanics
- **🔥 Combo System:** Eat fast to build combos! Each combo adds bonus score. Resets after 2.5s of inactivity.
- **⭐ Level Progression:** Every 5 foods consumed triggers a Level Up, increasing the serpent's speed.
- **⚙️ Deep Customization:** Toggle Sound Effects, Ambient Music, Screen Shake, Particles, and Grid visibility.

### 📱 Cross-Platform Controls
- **Desktop:** Arrow Keys or WASD
- **Mobile:** Swipe Gestures or On-screen D-Pad

## 🛠️ Tech Stack

- **Core:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Graphics:** HTML5 Canvas API (Hardware Accelerated)
- **Integration:** Telegram Web App API (Mini Apps)

## 🚀 Local Development

Want to run the game locally or contribute?

1. **Clone the repository:**
   ```bash
   gh repo clone ILIV007/arkeen-serpent
   # or
   git clone https://github.com/ILIV007/arkeen-serpent.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd arkeen-serpent
   ```

3. **Start a local server:**
   Since this is a static web app, you can use any local server. For example, using Python:
   ```bash
   python -m http.server 8000
   ```
   Or using Node.js (`http-server`):
   ```bash
   npx http-server
   ```

4. **Open in your browser:**
   Visit `http://localhost:8000`

## 📡 Telegram Mini App Integration

This game is fully optimized to run as a Telegram Mini App.

1. Create a bot via [@BotFather](https://t.me/BotFather).
2. Set the Web App URL to your deployed Cloudflare Pages URL (e.g., `https://arkeen-serpent.pages.dev/`).
3. Launch the game directly inside Telegram via [@ILIVIR3](https://t.me/ILIVIR3).

## 🎮 How to Play

1. **Choose Difficulty:** Select how fast and deadly the serpent will be.
2. **Select Realm:** Pick your visual environment.
3. **Survive & Score:** Eat the food to grow. Don't hit the walls or yourself!
4. **Chain Combos:** Eat multiple foods within 2.5 seconds to multiply your score.
5. **Level Up:** Consume 5 foods to increase your speed and advance to the next level.
